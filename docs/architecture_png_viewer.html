🏥 MediMaven System Architecture v1.1

Architecture Overview

MediMaven is a state-of-the-art medical question-answering system leveraging advanced AI/ML techniques for accurate, citation-backed medical information retrieval.

🌐 Frontend & CDN

  • React web application
  • CloudFront CDN for global distribution
  • S3 for static asset hosting

🔧 Backend Infrastructure

  • FastAPI for high-performance API
  • Auto Scaling Group with EC2 Spot Instances
  • Application Load Balancer
  • Docker containerization

🤖 RAG Pipeline

  • Hybrid Retriever: BM25 + Dense embeddings
  • 2-Stage Reranker: LambdaMART + BGE Cross-Encoder
  • Generator: Llama-3 8B (QLoRA fine-tuned, AWQ quantized)

💾 Data Storage

  • PostgreSQL for conversation history
  • Redis for caching
  • Qdrant for vector search
  • S3 for model storage

🚀 Model Training

  • Spark ETL for data processing
  • QLoRA fine-tuning for Llama-3
  • AWQ quantization for efficiency
  • LambdaMART for ranking
  • BGE Cross-Encoder training
  • WandB for experiment tracking

🔄 CI/CD & Monitoring

  • GitHub Actions for automated deployment
  • Docker Hub for container registry
  • CloudWatch for monitoring and logs

Key Features

  • ✅ Cost-optimized with EC2 Spot Instances
  • ✅ Auto-scaling based on load
  • ✅ Advanced two-stage ranking for accuracy
  • ✅ Model quantization for 4x faster inference
  • ✅ Comprehensive experiment tracking
  • ✅ Citation-backed responses
  • ✅ Sub-second response times
