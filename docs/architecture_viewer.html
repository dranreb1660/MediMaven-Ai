🏥 MediMaven System Architecture

Architecture Overview

This diagram shows the complete MediMaven system architecture including:

  • Frontend: React web application served via CloudFront CDN
  • Backend: FastAPI application running on AWS EC2 Spot instances with auto-scaling
  • RAG Pipeline: Hybrid retrieval, 2-stage reranking, and Llama-3 8B generation
  • Models: Fine-tuned Llama-3 (QLoRA), AWQ quantized models, LambdaMART, and ColBERT
  • Data Storage: PostgreSQL for conversations, Redis for caching, Qdrant for vector search
  • Training Pipeline: Offline ETL processing and model training with WandB experiment tracking
  • CI/CD: GitHub Actions with Docker deployment
  • Monitoring: CloudWatch for system metrics and logging
